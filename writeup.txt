Ok can we think about how to plan this?

We have three basic objects

1. Link
A link stores physics properties
It also has a list of the other links it connects to
And it keeps track of its "sibling" link

2. Elemenet
Generally each element has two links.
Elements also store physics properties

3. Circuit
A circuit is an ordered list of Links
Circuits also contain their own physics properties

Let's now further define the requirements of each object by going through our detection process

First: Detecting a circuit

1. Pick an element to start at
2. Pick a link within that element to start at

Now the circuit will be closed iff we reach the starting element sibling

3. Hop to the sibling link and add it to the circuit's list of links
4. Hop to the first link in its list
5. Repeat 3, 4, and 5 until the circuit is closed
